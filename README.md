# 栖页 · 浏览器起始页

**在线版：<https://jonathansssst.github.io/>**

一个安静、轻量、完全本地运行的浏览器主页。没有框架、没有构建步骤、没有账号，也不需要联网加载字体。

## 预览

打开 `index.html` 即可使用。

## 功能

- **时钟与问候**：中文日期、12 / 24 小时制、可显示秒数、按时间段变化问候语，可设置称呼。
- **搜索**：必应 / Google / 百度 / DuckDuckGo，可切换默认引擎；智能识别网址，支持 `/` 或 `Ctrl/Cmd + K` 聚焦搜索框。
- **书签**：添加、编辑、删除、拖动排序、撤销删除，最多 40 个。把网址从地址栏或链接直接拖入页面，会打开「添加书签」窗口并自动填入网址、站点名称，同时预览站点图标；在页面空白处粘贴网址也可直接添加。默认内置 7 个按本机浏览习惯挑选的公开站点（哔哩哔哩、GitHub、CSDN、DeepSeek、豆包、MC Wiki、Modrinth），不导入内网面板或私人链接；图标加载失败时自动使用同色系首字母。若之前保存的仍是未修改的旧版默认书签，首次载入会自动更新为这套推荐；已有自定义书签会保留。
- **剪贴板识别**：只有在浏览器已经授权读取剪贴板时，页面载入或重新聚焦才会自动提示剪贴板中的网址；点击快捷访问右侧的「剪贴板」按钮才会主动请求一次权限。未授权时直接按 `Ctrl/Cmd + V` 粘贴即可，不会反复弹出权限请求。
- **壁纸**：4 张内置渐变壁纸、本地图片上传、图片网址；支持拖拽图片到页面、柔化与遮罩调节。上传图片会自动压缩至最长边 2560px。「恢复默认壁纸」只切换画面，已上传的图片仍保留在「我的图片」中。
- **个性化**：搜索是否新标签页打开、显示秒数、24 小时制、称呼。
- **数据**：导出 / 导入 JSON 备份；上传的壁纸会一并封装进备份。
- **响应式**：桌面、平板与手机都能正常使用，支持键盘操作与减少动态效果偏好。

书签、设置与上传的壁纸只保存在浏览器本机（`localStorage` + `IndexedDB`），不会上传到任何服务器；搜索会直接请求你选择的搜索引擎，网站图标和图片网址会直接请求对应网站。页面底部的说明也提醒了本地存储这一点。

## 使用方式

### 直接打开

双击 `index.html`，或在浏览器地址栏输入它的 `file://` 路径。

### 设为浏览器主页

Chrome / Edge：

1. 打开「设置」→「启动时」。
2. 选择「打开特定网页」。
3. 添加上面 `index.html` 的本地路径。

如果浏览器对 `file://` 页面的存储限制较严格，可以在本目录启动一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080>，把它设为启动页。数据按「页面来源」保存，换地址后需要重新导入一次备份。

> 这个页面适合作为「启动页 / 主页」。如果要直接替换 Chrome 的新标签页，需要额外的浏览器扩展或企业策略。

### Firefox

「设置」→「主页」→「自定义网址」，填入页面地址即可。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl/Cmd + K` | 聚焦搜索框 |
| `Ctrl/Cmd + Enter` | 在新标签页打开搜索 / 网址 |
| `Esc` | 关闭搜索候选 / 关闭面板 |
| `Ctrl/Cmd + Z` | 撤销刚删除的书签（提示条显示时） |
| `Enter` | 搜索或访问网址 |
| `Ctrl/Cmd + V` | 在页面空白处粘贴网址，直接打开添加书签窗口 |

## 从网址添加书签

- 从浏览器地址栏、页面链接或任意窗口把网址拖进主页，会出现「松开，添加书签」提示；松开后自动填入网址和站点名称。
- 在页面空白处粘贴网址，效果相同。
- 浏览器允许且已经授权读取剪贴板时，载入或切回主页会提示剪贴板中的网址，点击「添加书签」即可；页面不会在未授权时反复触发权限请求。
- 点击快捷访问右侧的「剪贴板」按钮，会显式请求一次剪贴板权限并尝试添加当前剪贴板中的网址。
- 剪贴板读取需要浏览器授权；如果被拦截，使用粘贴或拖拽即可，不影响其他功能。
- 读取到的剪贴板内容只在本地用于识别网址，不会被保存或上传；不是网址时直接忽略。
- 已存在的同一网址不会重复创建，只会定位到已有书签。

## 数据说明

- 设置与书签：`localStorage`，键名 `qiyue-start-state-v1`。
- 上传的壁纸：`IndexedDB`（数据库 `qiyue-start`）。若浏览器不支持，会尝试回退到 `localStorage`。
- 清除浏览器站点数据会同时清除这些内容，建议定期「导出备份」。
- 备份中的自定义壁纸以 data URL 形式保存，因此备份文件可能较大，这是正常现象。

## 浏览器支持

面向现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。使用了原生 `<dialog>`、`popover`、可选链和 IndexedDB；在较旧浏览器中核心功能仍可用，但部分动画或提示层可能降级。
